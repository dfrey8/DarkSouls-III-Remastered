Установщики и файлы для загрузки размещаются в разделе [Releases](https://github.com/dfrey8/DarkSouls-III-Remastered/releases). Для веб-установки предназначен `DS3VR-Web-Setup.exe`. Бесплатное некоммерческое распространение. В пакет входят исходники и уведомления о лицензиях компонентов. Для восстановления модифицированных ресурсов требуется установленная Steam-копия игры. Проект не связан с FromSoftware, Bandai Namco или Valve.
